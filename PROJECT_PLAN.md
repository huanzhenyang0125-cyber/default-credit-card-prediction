# Project plan

1. **Phase 1 — Data fundamentals:** technical setup, official data and initial inspection complete; learner review and independent practice ongoing.
2. **Phase 2 — Exploratory data analysis:** Initial descriptive analysis complete; category definitions and unusual amounts need further investigation. See `reports/eda_summary.md`.
3. **Phase 3 — Baseline risk model:** Initial validation complete using a logistic regression pipeline; test set reserved. Probability calibration and further interpretation remain for later work.
4. **Phase 4 — Improvement and validation:** Model comparison, calibration, training-only CV, bootstrap, preliminary group checks and same-dataset held-out evaluation completed; external and temporal validation remain.
5. **Phase 5 — Decision framework:** Illustrative threshold/cost sensitivity, assumed PD/LGD/EAD arithmetic and fixed review-capacity evaluation completed; real-world intervention evaluation is unavailable.
6. **Phase 6 — Portfolio:** Planned. Prepare a research report, reproducible GitHub repository, dashboard and truthful résumé and interview material.

Only use information available before the prediction period. Keep the test set separate from model selection. Do not describe predictions or simulated scenarios as production lending decisions.
