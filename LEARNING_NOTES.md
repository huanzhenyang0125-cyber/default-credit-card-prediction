# Learning notes

- **Python**: a programming language used here to read and analyse data.
- **Variable / 变量**: a name referring to a value. `data` is the name used for the table read from the workbook.
- **Pandas**: a Python library for working with tabular data; commonly imported as `pd`.
- **DataFrame / 数据表**: Pandas' table structure, with rows and columns.
- **Row / 行**: one customer record in this dataset. **Column / 列**: a field, such as age or credit limit.
- **Index / 索引**: Pandas' row labels; they are distinct from the workbook's `ID` column.
- **`data.head(5)`**: show the first five rows; it does not remove the rest.
- **`data.shape`**: the number of rows and columns, in that order.
- **Target / 目标变量**: the outcome to predict. Here `default payment next month` is coded 1 for default and 0 for no default.
- **Default rate / 违约率**: in this dataset, the number of records with target 1 divided by the number of records. It describes this historical sample, not all customers.
- **Missing value / 缺失值**: an absent entry. No missing cells were detected by Pandas in this workbook; this alone does not prove all entries are valid.
- **Median / 中位数**: the middle value after sorting. Credit-limit values are in New Taiwan dollars.
- **Exploratory data analysis (EDA) / 探索性数据分析**: examining distributions, data quality and relationships before modelling.
- **Group default rate / 分组违约率**: defaults in a group divided by the group's total records. Always inspect group size alongside the rate.
- **Correlation / 相关性**: a measure of association; it does not prove that one variable causes another.
- **Logistic regression / 逻辑回归**: a baseline classification model producing estimated probabilities; estimates are not automatically well calibrated.
- **Training, validation, test / 训练、验证、测试集**: training fits the model, validation supports development, and the reserved test set assesses a finalized model. Prior full-data exploration limits how untouched a later test can be.
- **Precision / 精确率**: among records predicted to default, the fraction that actually defaulted. **Recall / 召回率**: among actual defaults, the fraction predicted to default.
- **ROC-AUC**: a ranking measure across thresholds. **Average precision** summarizes the precision–recall curve; it is not automatically the same as trapezoidal PR-AUC.
- **Calibration / 概率校准**: whether predicted probabilities agree with observed frequencies across groups; a post-processing method is not guaranteed to improve every metric.
- **Brier score**: mean squared difference between predicted probabilities and actual 0/1 outcomes; smaller is better.
- **Threshold / 阈值**: a probability cutoff for flagging a customer. Lowering it typically catches more defaults but also flags more non-defaults.
- **Bootstrap / 自助重采样**: repeatedly sampling the observed validation cases with replacement to study sampling variation; a fixed-model bootstrap does not capture every source of uncertainty.
- **Cross-validation / 交叉验证**: repeatedly train and assess on different partitions of the training set. A few random folds do not demonstrate stability across time or places.
- **False positive rate / 误报率**: the proportion of actual non-defaults flagged as defaults; it differs from the fraction of all customers flagged.
- **Expected loss / 预期损失**: a simplified formula is PD × LGD × EAD. PD is probability of default, LGD is loss given default, and EAD is exposure at default. Missing inputs must be explicitly assumed.
- **Review capacity / 复核容量**: the number of cases a team can investigate. Ranking customers by predicted risk can allocate limited slots; observing later default among selected cases does not prove that reviewing them would have prevented it.
